# Screenshots — SkyGuard AI

Product UI, pitch slides, and eval cards for SIH reviewers.

## Naming convention

Use lowercase kebab-case:

```text
01-network-map.png
02-station-hardware-anomaly.png
03-station-genuine-weather.png
04-alerts-inbox.png
05-reliability.png
06-control-replay.png
07-architecture-page.png
08-qc-eval-summary.png
09-overlay-metrics.png
10-recon-examples.png
pitch-slide-1.png …
```

Prefer PNG or WebP. Keep each file under ~2 MB when possible.
